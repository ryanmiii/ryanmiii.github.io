Robin Personal Assistant

Robin is a private AI assistant operated through a self-hosted OpenClaw instance. It is intended for the operator's personal use and is not offered as a public service.

Google services used

Gmail

Search and read messages, organize mail, and create drafts or send messages when explicitly requested.

Google Drive

Find and retrieve authorized files and, when requested, create or update content.

Google Calendar

Read schedules and create or update calendar events for personal planning and approved automations.

How access is used

Google account access is used only to carry out instructions and automations configured by the operator. Access is granted through Google OAuth and can be revoked by the operator at any time.

Read the Privacy Policy

Questions or privacy requests can be submitted through GitHub Issues. Do not include private Google data in a public issue.
