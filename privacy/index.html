Privacy Policy

Effective date: October 31, 2026

Overview

Robin Personal Assistant ("Robin") is a private, self-hosted AI assistant intended for personal use by its operator. This policy explains how Robin accesses, uses, stores, and shares Google user data.

Google user data accessed

  • Gmail: message content and metadata, labels, drafts, and information needed to send or manage messages.
  • Google Drive: file and folder metadata and the contents of files the authorized account permits Robin to access.
  • Google Calendar: calendars, event details, attendees, and information needed to create or update events.
  • Authentication data: OAuth tokens and account identifiers required to maintain authorized access.

How data is used

Google user data is used only to:

  • carry out requests initiated by the operator;
  • run automations explicitly configured by the operator;
  • produce relevant responses, summaries, drafts, files, and calendar actions; and
  • maintain, secure, and troubleshoot the private assistant.

Google user data is not used for advertising, profiling, or sale.

Processing, storage, and sharing

OAuth credentials are stored in credential storage controlled by the operator. Google user data may be processed on the operator-controlled OpenClaw host and may appear in task output, session history, logs, or memory when needed to complete a request.

When required to perform an AI-assisted task, relevant data may be transmitted to the AI model or service providers configured by the operator. Data is otherwise not disclosed to third parties except to operate the requested Google and AI services, protect the system, comply with law, or act on the operator's explicit direction.

Retention and deletion

Data is retained only in accordance with the operator's local OpenClaw configuration and operational needs. The operator can delete local sessions, logs, memories, generated files, and stored credentials. Revoking access in the Google Account security settings prevents future API access but does not automatically delete previously generated local output.

Security and user control

Access is limited through Google OAuth scopes and local access controls. The operator can review or revoke the application's Google access at any time through Google Account third-party connection settings and can remove local credentials from the OpenClaw host.

Changes to this policy

This policy will be updated if Robin's Google data access or processing practices materially change.

Contact

Questions or privacy requests can be submitted through the project's GitHub Issues page. Because issues are public, do not include private Google data, access tokens, or credentials.
